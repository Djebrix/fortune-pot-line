One kind, funny fortune for the houseplant on the windowsill — a single line
of at most 120 characters, written by `main.py` to `entry.txt`.

Entry for the [Fortune in a Pot](https://make.fun/bounty/u-golden-heron-44-fortune-in-a-pot-ded981e9) bounty on make.fun.

## Run

```sh
ENTRY_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

Stdlib only, no network. Deterministic: the same line every run.
